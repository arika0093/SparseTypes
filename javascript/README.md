# SparseTypes JavaScript codegen

`@sparsetypes/codegen` turns a server-generated OpenAPI 3.0 or 3.1 JSON document into JavaScript API and ChangePayload helpers with matching declarations. It is a development-time tool; generated files use standard `fetch` and have no SparseTypes runtime dependency.

The package is not published on npm yet. The sample uses the local package with a `file:` dependency; install dependencies in `javascript/` before installing the sample client. The checked-in package version is `0.0.0-placeholder`. Run `npm run pack:versioned -- --pack-destination <directory>` to build an npm tarball stamped with the NBGV `NpmPackageVersion`; the command restores the placeholder in `package.json` and `package-lock.json` afterward. The repository's `version.json` controls the computed version.

After installing the package as a development dependency, run `sparsetypes-codegen <openapi.json>` after the server has produced its OpenAPI document. By default, the tool writes a package to `node_modules/@sparsetypes/generated`, which applications can import as `@sparsetypes/generated`. Pass `--output <directory>` to choose another location. Prettier is a development dependency for formatting the codegen source; generation writes its output without invoking Prettier. The generated directory contains:

- `api.d.ts`: OpenAPI request, response, and DTO types generated by the embedded `openapi-typescript`.
- `models.d.ts` and `models.js`: DTO aliases, all-optional diff-input types named `Optional<ModelName>`, and schema-backed `parse<Model>` functions. Precision-sensitive diff inputs can use strings.
- `changes.js` and `changes.d.ts`: model-specific before/current diff functions that return the generated ChangePayload type or `undefined` when there is no change.
- `client.js` and `client.d.ts`: typed standard-fetch operations, raw-response variants, and `ApiError`.
- `index.js` and `index.d.ts`: public entry point for the generated module.

The generated module keeps ordinary DTO types aligned with the OpenAPI contract. Diff functions accept the corresponding `Optional<ModelName>` values, where properties may be omitted or `undefined`; `null` remains distinct and is accepted only when the DTO schema allows it. Pass baseline and edited values to `build<Model>ChangePayload`. It compares JSON-shaped values without mutation and accepts frozen or Immer-produced values.

Use `parse<Model>` on untrusted API responses to validate them against their OpenAPI schema before applying application-specific conversions.

Normal client operations decode successful responses and throw `ApiError` for non-success statuses. The error exposes `status`, the parsed `body` when applicable, and the original `response`. Each operation also has a `Raw` variant that returns the unread `Response` without status handling. Both accept ordinary `RequestInit` overrides; the client can also receive a base URL and custom `fetch`.

Precision-sensitive payload values such as decimals and 64-bit integers are encoded as strings where the server contract requires them. Use strings in editable state when the source value may exceed JavaScript number precision. A keyed-item snapshot must still match its ordinary DTO schema: if that schema uses a JSON number, codegen converts only exactly representable decimal or integer strings and throws rather than silently losing precision. A numeric value already decoded from JSON cannot recover precision lost during parsing.

The generator requires `x-sparsetypes` version 1 metadata on the payload and member schemas. It is emitted by the SparseTypes generator when the consumer enables payload-schema metadata. The metadata describes model/member associations, wire encodings, redaction, collection semantics, JSON key names, unassigned keys, and temporary identities. Documents without this metadata cannot generate ChangePayload helpers; ordinary API-only code generation is not the package's purpose.

The package requires Node.js 20 or newer. It has no publication or runtime configuration requirements.
